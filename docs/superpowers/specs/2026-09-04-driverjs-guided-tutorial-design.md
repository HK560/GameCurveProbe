# Driver.js 完整演示教程设计

## 背景与目标

GameCurveProbe 当前以四步界面组织窗口抓取、ROI 选取、死区标定、曲线测定和报告分析。新用户仍需理解许多前置条件、参数和报告指标。本功能引入 Driver.js，提供无需连接设备、无需真实抓图、无需检测结果也能从头看到尾的非阻塞演示教程。

教程首次使用时自动打开，也能从设置中随时重新启动。它只讲解和演示，不要求用户实际完成操作，不写入真实会话或配置，不调用抓图、虚拟手柄、检测、导入或导出接口。

## 用户体验

### 启动与完成

- 应用完成初始数据加载且首屏渲染后，检查 `gamecurveprobe_tutorial_completed` 本地标记。
- 标记不存在时自动开始教程；后端离线不影响教程运行。
- 设置弹窗新增“新手教程”卡片与“重新开始教程”按钮。点击后先关闭设置，再启动教程。
- 教程提供“上一步”“下一步”“跳过”和“完成”，不要求用户操作被高亮的控件。
- “完成”或明确“跳过”后写入完成标记，后续启动不再自动弹出。
- 刷新、页面关闭或异常中断不写入完成标记，下次仍自动启动。
- 首次教程结束后回到第一步；从设置重新启动的教程结束后回到启动前页面。

### 导览行为

- 教程按 7 章约 28 个节点组织，显示章节和节点进度。
- 跨页面节点先切换 `activeStep`，等待 Vue 完成渲染，再高亮目标。
- 浮层允许 Esc 退出；小窗口中自动滚动目标到可见区域。
- 优先高亮完整功能区域，只有关键操作才精确高亮按钮，避免浮层遮住复杂控件。
- 模拟倒计时和测定进度使用短动画，但用户始终可以立即继续。
- 教程文案、Driver.js 按钮和辅助说明完整支持中文与英文，并跟随当前语言。

## 教程内容

### 第一章：欢迎与流程概览

1. 介绍 GameCurveProbe 的用途。
2. 高亮顶部四步导航，解释完整检测路径。
3. 提醒真实检测前准备游戏与 ViGEmBus，并避免触碰实体手柄。

### 第二章：选择窗口与抓图

1. 高亮目标窗口选择器，演示选择一个虚构游戏窗口。
2. 解释 Auto、WGC 和 DXCAM 的差异与使用场景。
3. 介绍目标帧率对精度和性能的影响。
4. 高亮“开始抓图”，随后呈现模拟预览。
5. 说明连接状态、抓图后端、分辨率和常见异常提示。

### 第三章：ROI 选区

1. 高亮预览与模拟 ROI 框。
2. 说明应选纹理丰富、稳定、远离准星、UI 和动态物体的区域。
3. 解释 ROI 坐标、尺寸与质量总分。
4. 解释梯度、角点、信息熵和追踪稳定性。
5. 先展示低质量示例，再切换到优秀示例，直观说明差异。
6. 提醒捕获尺寸变化后需要重新框选。

### 第四章：死区与噪底检测

1. 自动进入第二步，解释内死区、外死区和有效检测行程。
2. 高亮“测定噪底”，用模拟 X/Y 结果解释背景微晃过滤。
3. 高亮实时输出开关，并说明真实操作会控制虚拟手柄。
4. 演示选择内死区目标、拖动滑块和使用微调步长。
5. 演示切换外死区目标及判断最大转速的方法。
6. 解释有效行程采样与全量程采样的区别。
7. 明确提示教程不会输出任何手柄信号。

### 第五章：参数与开始检测

1. 自动进入第三步，解释检测范围模式。
2. 介绍采样点数、稳定时间、采样时间、重复次数等现有参数。
3. 展示“快速预览”“推荐均衡”“高精度”三类参数建议，但不改真实配置。
4. 高亮开始按钮和全局快捷键。
5. 模拟倒计时、逐点采样、实时曲线、日志、稳定性评分和自动复测。
6. 说明保持游戏聚焦、不要触碰实体手柄及安全取消方法。

### 第六章：报告读取与解析

1. 自动进入第四步，加载基于现有 mock 曲线格式的标准示例报告。
2. 解释原始速度、归一化响应、拟合曲线与内外死区标线。
3. 解释模型名称、拟合参数、NRMSE、R² 和置信度的阅读方式。
4. 介绍线性、幂律、分段和 S 曲线结果及其操控含义。
5. 解释异常点、帧抖动和数据不足提示。
6. 演示曲线显隐、死区范围重算、JSON/CSV 导出和历史报告导入入口；不真正执行文件操作。

### 第七章：完成与下一步

1. 汇总真实操作的检查清单。
2. 提供“结束教程并从第一步开始”。
3. 告知用户可在设置中再次打开教程。

## 技术架构

### 模块职责

- `tutorialService.ts`：首次使用标记、启动来源、Driver.js 单例生命周期、完成与跳过语义。
- `tutorialSteps.ts`：中英文教程结构、目标选择器、章节信息、节点进入和离开动作。
- `tutorialDemo.ts`：窗口、抓图、ROI、噪底、死区、检测进度和分析报告的只读示例数据。
- `TutorialOverlay.vue`：连接 Driver.js、Vue 渲染周期、页面切换、目标等待、模拟动画和现场恢复。
- `App.vue`：承接首次自动启动与设置入口事件，不承载具体教程步骤。
- 现有页面组件：仅增加稳定、语义明确的 `data-tour` 锚点，并从教程上下文读取可选展示覆盖值。

### 状态隔离

页面展示值由正常会话数据与教程覆盖数据组合产生：

```text
真实 Session Store
       |
       +-- 正常模式 --> 页面真实数据
       |
       +-- 教程模式 --> Tutorial Demo Context --> 页面展示数据
```

教程覆盖值不写回 Pinia 会话、localStorage 配置或服务端。教程中的按钮仅作为高亮目标，Driver.js 不替用户触发其点击事件。退出时销毁 Driver.js 实例、模拟计时器和教程上下文，再恢复原页面。

### Driver.js 集成

- 将 `driver.js` 添加为正式前端依赖，并引入官方样式。
- 通过少量全局 CSS 变量和选择器覆盖，使浮层匹配现有中性黑白主题。
- 每个步骤使用稳定的 `data-tour` 选择器，避免依赖 Tailwind 类或翻译文本。
- 目标等待具有有限超时；目标缺失或组件渲染失败时记录警告并继续下一节点。
- 语言在教程中改变时，以同一逻辑位置重建 Driver.js，不重置教程或真实页面状态。

## 演示数据

- 窗口：虚构游戏标题、1920×1080、WGC、120 Hz。
- ROI：同时提供低质量与优秀质量快照，优秀示例满足继续条件。
- 噪底：提供合理的 X/Y 低幅速度值。
- 死区：示例内死区约 0.05、外死区约 0.95，并展示有效范围。
- 测定：提供逐点进度、实时日志、稳定与重试节点，动画可跳过。
- 报告：复用现有 mock 曲线的数据结构与拟合能力，选择包含足够点数和完整指标的标准示例。
- 三档参数预设只用于文案展示，并与当前界面真实可配置字段保持一致。

## 错误处理与可访问性

- `localStorage` 不可用、数据损坏或写入失败时静默降级，本次教程仍可运行。
- 重复快速启动只保留一个 Driver.js 实例。
- 退出路径统一清理动画、监听器、覆盖状态和浮层。
- 页面卸载时执行同样清理，禁止残留定时器或虚拟状态。
- 教程浮层层级高于页头、底栏和设置弹窗；焦点、键盘前后导航和 Esc 行为遵循 Driver.js 可访问性能力。
- 目标超时不会卡死整个教程，控制台警告包含节点标识以便排查。

## 测试策略

实现遵循测试驱动开发，每项行为先建立失败测试：

- 首次使用判定、完成标记、跳过标记、异常中断不标记及损坏存储降级。
- 教程步骤顺序、章节编号、必要节点和中英文文案完整性。
- 跨步骤进入动作、DOM 等待和目标缺失跳过。
- Driver.js 单例、重复启动、Esc、跳过、完成和卸载清理。
- 教程覆盖状态不修改真实会话、用户配置或调用危险 API，退出后恢复原页面。
- 设置入口关闭弹窗后启动，以及初始化完成后的首次自动触发。
- 关键 `data-tour` 锚点存在性。
- 全部前端单元测试、Vue/TypeScript 类型检查和生产构建。
- 在现有浏览器 E2E 能稳定承载时，覆盖“首次自动打开、跨越四步、完成、刷新不再打开、设置重开”的主路径；若浏览器环境不具备 Driver.js 所需 DOM 能力，则用组件集成测试覆盖同一状态机。

## 验收标准

- 全新本地环境首次打开时，教程在初始化完成后自动出现。
- 不连接游戏、抓图后端或 ViGEmBus，也能完整观看全部七章。
- 教程自动切换四个页面并展示足够的模拟内容来解释所有核心功能。
- 教程期间不会启动真实抓图、虚拟手柄输出、测定、导入或导出，也不会覆盖用户配置。
- 完成或跳过后不再自动弹出；设置入口始终可以重新启动。
- 所有退出路径恢复真实状态且无浮层、计时器或演示数据残留。
- 中英文均无缺失文本，常规桌面尺寸与较小窗口均可完成教程。
- 前端测试、类型检查和生产构建通过。

## 非目标

- 不将教程改造成强制完成真实操作的交互式任务。
- 不自动控制用户游戏窗口、物理或虚拟手柄。
- 不为教程新增服务端持久化或账户级同步。
- 不改变现有四步业务流程、算法或报告格式。
