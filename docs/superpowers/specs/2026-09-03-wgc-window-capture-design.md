# GameCurveProbe WGC 独立窗口捕获设计

- 日期：2026-09-03
- 状态：用户已确认交互设计，待书面复核
- 范围：替换 `auto` 的桌面裁剪回退行为，完善 WGC 窗口状态与测量安全联动

## 1. 目标与边界

正式捕获链路使用 Windows Graphics Capture（WGC）按 HWND 获取目标窗口内容。目标窗口被其他窗口部分或完全遮挡时，预览、ROI 分析和测量仍应接收目标窗口自身画面。

Windows 无法保证已经最小化的游戏继续渲染，因此本功能不宣称支持最小化后持续采集。检测到最小化时停止或拒绝测量、立即回中虚拟手柄，并提示用户不要最小化目标窗口。恢复窗口后允许重新绑定，但不自动恢复被中断的任务。

## 2. 后端选择规则

- `wgc` 是正式窗口捕获后端，使用 `windows-capture` 提供的 Windows Graphics Capture 接口。
- `auto` 只尝试 `wgc`。WGC 不可用、启动失败、黑帧或停帧时返回明确错误，不再静默回退到桌面捕获。
- `dxcam` 仅作为用户手动选择的屏幕区域兼容模式保留。该模式捕获桌面合成结果，窗口被遮挡时会包含遮挡内容。
- 前端在选择 `dxcam` 时必须显示持续可见的警告，不得把它描述为独立窗口捕获。
- `CaptureInfo` 暴露稳定的捕获能力标记 `occlusion_safe`：WGC 为 `true`，dxcam 为 `false`。

## 3. 帧所有权与数据流

`CaptureService` 是底层后端的唯一读取者。底层帧进入服务后，通过同一份最新帧状态分发给预览、ROI 分析、底噪和测量消费者，消费者不得直接并发调用后端。

切换窗口、重新绑定或切换后端时：

1. 设置旧捕获会话的停止信号；
2. 关闭旧后端并等待读取线程退出；
3. 清除旧帧和旧窗口状态；
4. 创建新捕获会话；
5. 只有新会话的回调可以发布帧。

每次绑定使用会话代号隔离迟到回调，防止已关闭 HWND 的帧污染新窗口。

## 4. WGC 启动健康检查

WGC 在限定观察期内必须收到至少 10 个由捕获回调产生、`frame_id` 严格递增、尺寸一致且非空的帧。

不得用图像像素相等判断 WGC 是否重复或停滞。静止场景可以连续产生内容完全相同的合法帧；健康判定只依据捕获回调是否继续产生新的递增帧号。

连续 10 帧的亮度均值和标准差都不高于 1 时返回 `CAPTURE_BLACK_FRAME`。观察期内不足 10 个新回调帧返回 `CAPTURE_STALLED`。两种错误都不得触发 `auto` 向 dxcam 降级。

## 5. 运行时窗口状态

- **被遮挡**：WGC 正常工作，不产生警告，不切换后端。
- **最小化**：产生 `WINDOW_MINIMIZED`；取消活动测量并回中；前端提示“目标窗口已最小化，请恢复窗口后重试”。
- **恢复**：允许用户重新绑定 WGC；不自动续跑旧测量。
- **关闭**：产生 `WINDOW_GONE`，释放捕获并进入 detached。
- **客户区尺寸变化**：清除旧 ROI 并产生 `ROI_INVALIDATED`；活动测量安全失败并回中。
- **运行期无新回调帧**：产生 `CAPTURE_STALLED`，缓存帧不能冒充新帧。

## 6. 测量前置检查与错误处理

测量任务创建前原子快照捕获、ROI、配置和底噪，并验证：

- 当前后端已附加；
- 当前窗口存在且未最小化；
- WGC 在健康时间窗内产生过新帧；
- ROI 完全位于当前客户区。

运行期间发生 `WINDOW_MINIMIZED`、`WINDOW_GONE`、`CAPTURE_STALLED` 或 `ROI_INVALIDATED` 时，任务进入 failed，保留稳定错误码，并在任务结束前完成虚拟手柄回中和控制器资源释放。

## 7. API 与前端表现

捕获响应包括实际后端和 `occlusion_safe`。健康接口返回窗口存在、最小化、帧龄、帧号、尺寸和最近错误。

前端默认选择 `auto`。选择 `dxcam` 时显示：“屏幕区域兼容模式，窗口被遮挡时会捕获遮挡内容。”WGC 错误只提供重试、恢复窗口或手动选择兼容模式，不自动替用户切换。

最小化提示只说明不要最小化目标窗口，不尝试自动恢复或操作用户窗口。

## 8. 测试与验收

自动化测试必须覆盖：

- 静态像素但持续产生新回调的 WGC 帧通过启动检查；
- `auto` 在 WGC 失败时不调用 dxcam；
- 强制 `dxcam` 仍可使用且能力标记为不抗遮挡；
- 最小化时拒绝新测量并取消活动测量；
- 恢复后可以重新绑定；
- 窗口关闭、客户区尺寸变化、停帧和黑帧返回对应错误；
- 所有异常路径最终回中；
- 前端显示兼容模式警告；
- Python、TypeScript、前端测试、生产构建、PyInstaller 和 EXE smoke 全部通过。

硬件验收需使用真实 Windows 10/11 游戏窗口验证：前景、完全遮挡、跨窗口切换、恢复最小化、窗口关闭和尺寸变化。自动化 stub 测试不能替代真实 WGC 遮挡测试。
