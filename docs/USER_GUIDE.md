# GameCurveProbe 2.0 用户使用手册

本文档详细介绍 GameCurveProbe 2.0 WebUI 的功能架构、四步向导工作流以及常见问题排查。

---

## 1. 系统架构与技术特点

GameCurveProbe 2.0 彻底重构了交互体系，采用现代 WebUI 配合本地轻量服务的架构：

- **服务端**：基于 FastAPI 与 Uvicorn 构建，通过 Token 鉴权和本地 Origin 校验确保安全。
- **图形抓取**：采用 Windows.Graphics.Capture (WGC) 作为主抓图管线，消除传统 GDI/DXGI 截屏可能出现的黑屏或降频问题，并提供 DXGI 自动降级保障。
- **计算机视觉**：内置多维度特征质检评估（ROI Analyzer），综合边缘熵、角点特征、Sobel 梯度打出 0~100 质量分；结合抗微晃的 Lucas-Kanade 稀疏光流测速。
- **数据拟合**：采用非线性最小二乘法，结合均方根误差（NRMSE）自动判定线性（Linear）、指数幂律（Power Law）或 Logistic S型曲线。
- **前端交互**：基于 Vue 3 + TypeScript + TailwindCSS + ECharts 开发，支持高刷流式帧预览与交互式选区。

## 2. 环境准备与运行方式

### 2.1 安装 ViGEmBus 虚拟手柄总线
GameCurveProbe 需要向操作系统模拟 Xbox 360 手柄信号，请确保已安装 ViGEmBus 驱动：
- 官方发布页：https://github.com/nefarius/ViGEmBus/releases

### 2.2 启动程序
在终端执行：
```powershell
uv run gamecurveprobe
```
程序启动后将在命令行打印本地服务地址（如 `http://127.0.0.1:8765/?token=xxxx`），并在 1 秒后自动唤起系统默认浏览器。

## 3. 四步向导操作流程

### 新手演示教程

首次使用 WebUI 时，程序会在初始化完成后自动打开完整的新手教程。教程使用内置示例窗口、ROI、噪底、死区、采样进度和分析报告，自动带你浏览四个步骤；即使未启动游戏、未安装或启用虚拟手柄、后端离线，也可以完整观看。

教程仅用于讲解，不会绑定真实窗口、输出虚拟手柄信号、启动检测、改写用户参数或执行报告导入/导出。可以使用“上一步”“下一步”浏览，或选择“跳过教程”。正常完成或明确跳过后，下次启动不再自动弹出；若教程被刷新或异常中断，则下次仍会自动打开。

需要再次观看时，点击页面顶部的“设置”，在“新手演示教程”卡片中选择“重新开始教程”。从设置进入的教程结束后会返回启动教程前所在的步骤。

### 第一步：窗口与抓图配置 (Window & Capture)
1. 在“目标游戏窗口”下拉菜单中选择运行中的游戏窗口。
2. 推荐选择 `Auto` 抓图引擎及 `120 FPS` 帧率，点击“开始抓图”。
3. 画面就绪后，在画面预览区用鼠标左键拖拽框选 ROI 区域：
   - 建议选择屏幕中央、纹理丰富（如建筑物纹理、植被、清晰地表）、避开动态 UI 和准星的区域。
   - 观察右侧“特征分析 (ROI 质量)”卡片，若评分达到 60+ 分即可点击“下一步：手柄死区标定”。

### 第二步：手柄死区标定 (Deadzone Calibration)
1. **静止噪底校准**：
   - 保持手柄完全静止，点击“测定噪底”。系统将采样 0.5 秒画面背景微动，用于后续测速扣除。
2. **内死区探测**：
   - 选择 `0.005` 或 `0.001` 步长，点击“激活摇杆实时输出”。
   - 观察游戏内视角是否有转动迹象。当刚出现持续微动时，点击“设为内死区”。
3. **外死区探测**：
   - 将输出滑动至 0.85~1.00 区间，寻找角速度达到游戏上限的临界推杆点，点击“设为外死区”。
4. 点击“下一步：曲线测定”。

### 第三步：全自动曲线测定 (Curve Measurement)
1. 选择测定范围（默认“全范围”）与采样点数（推荐 17 点）。
2. 点击“开始稳态测定”。测定期间程序会自动输出各档位摇杆数值，请勿触碰物理手柄。
3. 系统将实时显示当前测定进度、各点角速度及稳定性评分。若有微晃失稳，系统将自动复测。
4. 全量测定完成后，点击“下一步：拟合分析与导出报告”。

### 第四步：拟合分析与报告导出 (Analysis & Export)
1. 在图表中可交互查看角速度曲线（左 Y 轴）与归一化响应曲线（右 Y 轴），内/外死区标记线一目了然。
2. 查看顶部“曲线数学模型”分析卡片，系统将给出线性度、指数系数及拟合置信度。
3. 点击“导出 JSON”或“导出 CSV”，即可将曲线数据以 ControllerMeta 曲线工具支持的格式保存到本地。ControllerMeta 是需要额外下载安装的手柄检测工具，请前往 [ControllerMeta 官网](https://www.controllermeta.com/) 下载，安装后可用它继续编辑和转换曲线。
